# 🌀 Rasengan CV

A real-time Computer Vision project built with **Python, OpenCV, and MediaPipe** that creates an animated Rasengan effect on the user's palm.

## Features
- 👋 Hand tracking
- 🎯 Palm center detection
- 💙 Pulsating Rasengan
- ✨ Three-layer particle animation
- 🌪️ Dynamic rotating effects

## Tech Stack
- Python
- OpenCV
- MediaPipe
- NumPy

> 🚧 This project is currently under development. More effects and features will be added soon.
